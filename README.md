# Cine Cinema - Shared Contract

This repository contains the shared communication contract
between the Cinema Side and Movie/Fan Side applications.

## Kafka Topics

1. cinema.catalog
2. reservation.requests
3. reservation.results

## Repository Structure

- kafka-contract.md - Complete Kafka communication specification.
- samples/catalog.json - Movie and showtime message.
- samples/reservation-request.json - Customer reservation request.
- samples/reservation-result.json - Reservation result.

## Important

Both developers must follow the same Kafka contract.

Changes must be discussed and approved by both developers.
